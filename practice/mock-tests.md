## 模考注意事项

### 模考前
- [ ] 准备好答题纸、铅笔、橡皮
- [ ] 选择安静的环境
- [ ] 确保不会被打扰
- [ ] 调整好心态，当做真实考试

### 模考中
- [ ] 严格按照考试时间
- [ ] 不要中途暂停或查词典
- [ ] 模拟真实考试压力
- [ ] 听力只播放一遍

### 模考后
- [ ] 立即对答案
- [ ] 详细分析错题
- [ ] 记录本次模考情况
- [ ] 制定改进计划
- [ ] 不要马上再做一套（间隔至少3天）

## 学习建议

**如果分数停滞不前**：
1. 检查学习方法是否正确
2. 是否认真分析错题
3. 是否只是刷题而不总结
4. 考虑调整学习策略或寻求帮助

**如果某项特别弱**：
1. 加大该项练习时间（占总时间40-50%）
2. 针对性地使用专项教材
3. 考虑该项的一对一辅导
4. 找出具体问题所在（词汇？技巧？速度？）

**如果进步明显**：
1. 总结有效的学习方法
2. 保持当前学习节奏
3. 适当提高练习难度
4. 继续查漏补缺

---

**记住**：模考不是目的，找到问题并改进才是关键！

每次模考都是一次宝贵的学习机会。

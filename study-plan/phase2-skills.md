# 第二阶段：技能提升期（8-10周）

## 阶段目标

- 各科目达到6.0-6.5水平
- 掌握各题型的解题技巧
- 建立自己的答题策略
- 口语和写作有明显提升

## 每日学习安排（3-4小时）

### 上午/集中时间段（2小时）

**阅读专项训练（60分钟）**
- 每天完整3篇阅读（限时60分钟）
- 精读1篇文章，分析长难句
- 整理同义替换词汇
- 总结各题型技巧

**写作练习（60分钟）**
- Week 1-4：Task 1（图表作文）
  - 每周2-3篇完整写作
  - 学习范文，积累表达
  - 重点：数据描述、趋势表达
- Week 5-8：Task 2（议论文）
  - 每周2-3篇完整写作
  - 建立观点库
  - 练习论证逻辑
- Week 9-10：Task 1 + Task 2 组合练习

### 下午/晚间（1.5-2小时）

**听力强化（60分钟）**
- 每天1套完整听力（40分钟）
- 精听错题部分
- 总结听力场景词汇
- 练习跟读提高反应速度

**口语训练（45分钟）**
- Part 1：日常话题（15分钟）
- Part 2：话题卡练习（20分钟）
- Part 3：深度讨论（10分钟）
- 录音+回听+改进

**词汇复习（15分钟）**
- 复习之前背过的词汇
- 学习同义词替换
- 场景词汇整理

## 分项训练重点

### 听力（目标6.0-6.5）

**Week 1-3：Section 1-2突破**
- 掌握个人信息、日期、数字的快速记录
- 熟悉租房、旅游、购物等场景
- 练习边听边写

**Week 4-6：Section 3-4攻克**
- 学术讨论场景熟悉
- 讲座笔记法练习
- 提高同义替换识别能力

**Week 7-10：整体提升**
- 每天1套完整题
- 错误率控制在30%以下
- 速记能力强化

**听力技巧**：
- 关键词定位
- 预判答案
- 注意转折词（but, however, actually）
- 同义替换敏感度

### 阅读（目标6.5-7.0）

**Week 1-3：题型专项**
- 判断题（T/F/NG）
- 填空题
- 选择题
- 匹配题

**Week 4-6：速度提升**
- 60分钟完成3篇并保证准确率
- 略读、扫读技巧
- 定位能力训练

**Week 7-10：难度提升**
- 使用剑桥11-15
- 复杂文章结构分析
- 错误率控制在20%以下

**阅读技巧**：
- 先看题后读文
- 关键词画线定位
- 同义替换是核心
- 时间分配：20分钟/篇

### 写作（目标6.0-6.5）

**Task 1（图表作文）Week 1-4**

核心能力：
- 数据描述准确
- 趋势表达多样
- 对比分析清晰
- 150字以上

常用表达积累：
```
- 上升：increase, rise, grow, climb, soar
- 下降：decrease, decline, drop, fall, plummet
- 波动：fluctuate, vary
- 保持：remain stable, maintain, stay constant
```

**Task 2（大作文）Week 5-10**

文章结构：
```
Introduction（引入）
- 改写题目
- 表明观点

Body Paragraph 1（主体段1）
- Topic sentence（主题句）
- Explanation（解释）
- Example（例子）

Body Paragraph 2（主体段2）
- Topic sentence
- Explanation
- Example

Conclusion（结论）
- 总结观点
- 不要新信息
```

建立观点库（分类整理）：
- 教育类
- 科技类
- 环境类
- 社会类
- 政府类

**写作提升方法**：
- 每周至少3篇完整作文
- 背诵20篇优秀范文
- 建立自己的句型库
- 找partner互相批改（或使用批改网）

### 口语（目标6.0-6.5）

**Part 1（4-5分钟）**
- 准备50个常见话题
- 每个话题准备2-3个答案
- 重点：流利度和自然度

常见话题：
- Work/Study
- Hometown
- Accommodation
- Hobbies
- Food
- Travel
- Weather

**Part 2（3-4分钟）**
- 准备50-80个话题卡
- 练习1分钟准备+2分钟叙述
- 建立万能素材库（人物、地点、事件可复用）

**Part 3（4-5分钟）**
- 基于Part 2的深度讨论
- 练习批判性思维
- 高级词汇和复杂句型使用

**口语提升方法**：
- 每天录音练习30分钟
- 模仿native speaker的语音语调
- 使用口语陪练APP（如HelloTalk、Cambly）
- 参加英语角或找语伴

## 常见问题

**Q: 写作找谁批改？**
A:
1. 使用批改网（句酷批改网）
2. 淘宝找雅思老师批改（15-30元/篇）
3. 加入学习小组互相批改
4. 使用Grammarly检查语法

**Q: 口语没有对练怎么办？**
A:
1. 自己录音反复听
2. 使用APP找语伴（HelloTalk、Tandem）
3. 参加线上英语角
4. 考虑买几节外教口语课

**Q: 这个阶段需要做多少套题？**
A:
- 听力：至少30套完整练习
- 阅读：至少25套完整练习
- 写作：Task 1至少15篇，Task 2至少20篇
- 口语：每个Part每天练习

**Q: 进步不明显怎么办？**
A:
1. 检查学习方法是否正确
2. 是否真的投入了足够时间
3. 找出薄弱环节重点突破
4. 考虑针对弱项报单项班

## 进入下一阶段的标准

满足以下大部分条件：
- 模考平均分达到6.0以上
- 各单项不低于5.5
- 完成8周以上的系统学习
- 距离考试时间4-6周

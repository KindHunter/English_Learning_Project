# 第三阶段：冲刺练习期（4-6周）

## 阶段目标

- 模考成绩稳定在目标分数
- 调整到最佳考试状态
- 查漏补缺，巩固弱项
- 熟悉考试流程和时间管理

## 本阶段特点

- **以考代练**：每周至少2次完整模考
- **真题为主**：只做剑桥真题11-18
- **严格计时**：完全按照考试时间
- **状态调整**：调整作息到考试时间
- **心态管理**：培养考试心态

## 每日学习安排（3-4小时）

### 模考日（每周2-3次）

**上午9:00-12:00（按照实际考试时间）**
- 9:00-9:30 听力（30分钟答题+10分钟誊写答案）
- 9:30-10:30 阅读（60分钟）
- 10:30-11:30 写作（60分钟：Task1 20分钟 + Task2 40分钟）

**下午**
- 对答案，分析错题
- 整理错误原因
- 补充薄弱知识点

**晚上**
- 口语模考（11-14分钟完整流程）
- 录音并自我评估

### 非模考日

**上午（2小时）**
- 弱项专项训练
- 复习错题本
- 背诵词汇和表达

**下午（1.5小时）**
- 口语练习（当季题库）
- 写作范文背诵和仿写
- 听力精听训练

### Week 2：专项突破，强化弱项

- 每天1篇完整写作
- 背诵10篇范文
- 建立观点库
- 找老师批改

- 每天1小时口语练习
- 当季50个话题准备
- 外教陪练3-5次
- 录音对比改进

- [ ] 考试流程烂熟于心

### Week 4：考前调整，保持状态

**目标**：最佳状态迎接考试

**考前7天**
- 停止做新题
- 复习错题本
- 巩固薄弱知识点
- 保持每天适度练习

**考前3天**
- 轻度复习
- 看看笔记和总结
- 调整作息
- 放松心态

**考前1天**
- 准备考试用品
- 熟悉考场路线
- 早睡
- 不要再学习新内容

## 模考真题使用建议

### 推荐使用顺序

**第一阶段用**：剑4-10（基础阶段）
**第二阶段用**：剑11-14（提升阶段）
**第三阶段用**：剑15-18（冲刺阶段）

### 真题使用原则

1. **严格模考**：完全按考试时间和流程
2. **一套不浪费**：做完要充分分析
3. **留2套考前用**：考前一周做最新的2套
4. **不重复做**：真题有限，不要反复做同一套

## 错题本整理方法

### 听力错题本
```
题目：剑17 Test1 Section2 Q15
错误原因：同义替换没听出来（"discount" → "reduced price"）
知识点：购物场景词汇
改进：加强同义替换敏感度
```

### 阅读错题本
```
题目：剑17 Test1 Passage2 Q20 (T/F/NG)
错误原因：理解偏差，选了F应该选NG
原文定位：第3段第2句
技巧：F是明确错误，NG是文中未提及
```

### 写作记录
```
题目：Some people think...
分数：6.0
问题：论证不够充分，缺少具体例子
优点：结构清晰，语法错误少
改进：背诵论证例子库
```

### 口语记录
```
话题：Describe a place you visited
问题：说得太短（只说了1分钟）
卡顿：不知道如何描述感受
改进：准备万能素材，背诵形容词
```

## 应考技巧

### 听力考试
- 利用读题时间预判答案
- 注意大小写和单复数
- 没听到的赶紧跳过，不要恋战
- 检查拼写

### 阅读考试
- 先易后难，不要按顺序做
- 严格控制时间（20分钟/篇）
- 注意同义替换
- 不确定的也要填答案

### 写作考试
- Task 1控制在20分钟内
- Task 2至少留40分钟
- 列提纲（2-3分钟）
- 留时间检查语法（2-3分钟）

### 口语考试
- 放松，把考官当朋友聊天
- 不知道的话题可以适当转移
- 说错了不要停顿，继续说
- 语速不要太快，清晰度更重要

## 常见问题

**Q: 模考分数一直提不上去怎么办？**
A:
1. 检查是否认真分析错题
2. 是否真的理解了技巧
3. 可能遇到瓶颈期，坚持就会突破
4. 考虑找老师点拨

**Q: 考前紧张怎么办？**
A:
1. 充分的准备是信心的来源
2. 考前做过的模考都能稳定发挥就好
3. 深呼吸，告诉自己已经准备好了
4. 实在不行，把它当作一次练习

**Q: 考试时间不够怎么办？**
A:
1. 模考时严格按时间练习
2. 学会取舍，先拿能拿的分
3. 提高做题速度，多练习

**Q: 需要预测题吗？**
A:
1. 口语可以看当季题库（准确度高）
2. 写作大作文话题可以看预测准备素材
3. 听力阅读不要依赖预测，打好基础

## 成绩查询

- 纸笔考试：13天后可查
- 机考：3-5天后可查
- 查询网站：IELTS官网（ielts.org）

## 如果成绩不理想

1. **分析原因**：
   - 哪个单项拖后腿
   - 是发挥失常还是准备不足

2. **调整计划**：
   - 针对弱项加强训练
   - 考虑报班

3. **再战雅思**：
   - 两次考试间隔至少4周
   - 充分准备后再考

4. **保持信心**：
   - 很多人都不是一次成功
   - 总结经验，再接再厉

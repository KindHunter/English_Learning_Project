# 雅思学习资源库

## 项目定位

这是一个雅思（IELTS）学习资源库，收集和整理可以**直接使用**的学习材料。

所有资源都是实用导向，可以直接背诵、练习和应用到雅思备考中。

## 目标用户

- 正在准备雅思考试的自学者
- 需要实用学习材料的备考者
- 希望系统整理雅思知识点的学习者

## 资源分类（规划中）

### 📚 词汇资源
- 核心词汇表（按话题和场景分类）
- 同义词替换
- 高频搭配

### ✍️ 写作资源
- Task 1 模板和句型
- Task 2 论证段落和观点
- 范文集
- 万能表达

### 🗣️ 口语资源
- Part 1/2/3 话题答案示例
- 常用表达和句型
- 话题词汇

### 🎧 听力资源
- 场景词汇
- 常见表达

### 📖 阅读资源
- 学术词汇
- 信号词和逻辑词

## 使用方式

1. 浏览对应分类找到需要的资源
2. 直接背诵、练习或应用
3. 根据自己的进度逐步积累

## 项目原则

- ✅ 实用性优先：只收录可直接使用的内容
- ✅ 内容准确：确保语言地道、用法正确
- ✅ 持续更新：循序渐进地完善资源库

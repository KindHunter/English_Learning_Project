# 雅思学习资源库

## 项目定位

这是一个雅思（IELTS）学习资源库，收集和整理可以**直接使用**的学习材料。

所有资源都是实用导向，可以直接背诵、练习和应用到雅思备考中。

## 目标用户

- 正在准备雅思考试的自学者
- 需要实用学习材料的备考者
- 希望系统整理雅思知识点的学习者

## 资源分类（规划中）

### 📚 词汇资源
- 核心词汇表（按话题和场景分类）
- 同义词替换
- 高频搭配

### ✍️ 写作资源
- Task 1 模板和句型
- Task 2 论证段落和观点
- 范文集
- 万能表达

### 🗣️ 口语资源
- Part 1/2/3 话题答案示例
- 常用表达和句型
- 话题词汇

### 🎧 听力资源
- 场景词汇
- 常见表达

### 📖 阅读资源
- 学术词汇
- 信号词和逻辑词

## 词汇数据模型

项目使用 JSON 格式存储词汇数据，采用标准化的数据模型。

### 标准模型结构

```json
{
  "word": "单词",
  "phonetic": "音标",
  "partOfSpeech": "词性",
  "definition": "中文释义",
  "category": "分类标签",
  "frequency": "使用频率 (high/medium/low)",
  "examples": ["例句1", "例句2"],
  "synonyms": ["同义词1", "同义词2"]
}
```

### 分类标签说明

- `listening-rental` - 听力场景：租房
- `listening-tourism` - 听力场景：旅游
- `writing-environment` - 写作话题：环境
- `writing-education` - 写作话题：教育
- `writing-technology` - 写作话题：科技
- `writing-chart` - 写作：图表描述
- `speaking-personality` - 口语：性格描述
- `academic` - 学术通用词汇

### 示例文件

查看 `单词数据/example-vocabulary.json` 了解完整的数据格式示例。

## 使用方式

1. 浏览对应分类找到需要的资源
2. 直接背诵、练习或应用
3. 根据自己的进度逐步积累

## 项目原则

- ✅ 实用性优先：只收录可直接使用的内容
- ✅ 内容准确：确保语言地道、用法正确
- ✅ 持续更新：循序渐进地完善资源库
